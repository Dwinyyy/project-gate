# ADR 0005 — Maps and geographic authority

Status: accepted planning decision from the approved master blueprint; implementation is tracked separately.

## Context

Map rendering and tile delivery must be separate from access authorization, physical evidence, virtual position, public presence and hostile exposure.

## Decision

MapLibre GL JS with licensed MapTiler tiles; PostGIS server discovery and proximity decisions; foreground native location adapter and separately gated deterministic development simulator.

## Consequences and alternatives

Confirm licensing, provider budget and real-device performance. No production GPS override; uncertainty produces explanation/retry rather than automatic irreversible punishment. Approximate presence is opt-in and never a travel-history API.

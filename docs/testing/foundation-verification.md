Global sign-out revokes refresh sessions but previously issued access tokens follow provider expiry/revocation behavior. DevTools cannot be disabled as a security boundary, and these checks cannot promise zero vulnerabilities. Characters, gameplay, economy, location and mobile packaging are not implemented. A01–A28 gameplay cases remain not-run. PostGIS belongs with geographic queries.
